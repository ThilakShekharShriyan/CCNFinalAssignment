# Canvas research plan template mapping

Download the official **Research Plan template** from Canvas (Navrati’s course). Use the table below to paste content from [RESEARCH_PLAN_SUBMISSION.md](RESEARCH_PLAN_SUBMISSION.md) into the correct template slots. If your template uses different headings, merge rows or duplicate a paragraph where two prompts are similar—**do not leave any required prompt blank**.
